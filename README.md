# Jumia-inspired E-commerce Case Study

A front-end-only learning project built with HTML, CSS and vanilla JavaScript. It is inspired by common Jumia shopping patterns, but is not affiliated with Jumia.

## Pages
- `index.html` — home page, category shortcuts, rotating hero carousel, product grids and footer
- `product.html` — product detail, delivery options, specifications and customer feedback
- `cart.html` — cart quantity controls, remove item and summary
- `checkout.html` — delivery form, payment demo and order summary
- `account.html` — account navigation
- `help.html` — help topics, FAQ accordion and demo contact form
- `login.html` — demo login form
- `register.html` — demo registration form

## Run locally
1. Extract the ZIP.
2. Open the `jumia_case_study` folder in VS Code.
3. Run `index.html` with Live Server (recommended), or open it directly in your browser.

## Notes
- Cart contents use `localStorage` and persist in the same browser.
- The product images are loaded from Unsplash URLs and need an internet connection.
- Font Awesome icons and Google Fonts are CDN-based and need an internet connection.
- Checkout, login, registration and support are demo interactions only. There is no backend, account database, inventory system or real payment processing.
- Prices and review figures are sample case-study data. The real Jumia brand, exact website layout, inventory and trademarks belong to their respective owners.
